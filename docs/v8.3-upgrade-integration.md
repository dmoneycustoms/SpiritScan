# SpiritScan NSCB v8.3 — Upgrade Integration Notes

This build merges the full "Spiritscan full update" (128-page upgrade spec)
into the working SpiritScan GitHub app (`com.nscb.spiritscan`).

## What was integrated

### New engines (`engines/`)
- **FusionEngine** — multi-channel weighting (QIDA 0.32 / SDE 0.28 / Omega 0.22 /
  Mag 0.10 / Residual 0.08), temporal smoothing via 12-frame `TemporalWindow`,
  confidence + stability models, interference suppression.
- **HudEngine / HudState** — composite bar, confidence, stability, interference
  flag, micro-bars.
- **DiagnosticsEngine / DiagnosticsState** — FPS, frame time, fusion time,
  magnetic jitter.
- **PerformanceEngine / PerformanceState** — warm-start, frame skip, shader
  throttle, frame-time smoothing.
- **ShaderEngine** — distortion / pulse / spectral / interference flash /
  magnetic ripple / entity glow color models.
- **ResidualEngine** — Welford baseline, residual level/confidence/delta + notes.
- **InterferenceEngine** — RF spike, EMF spike, mag jitter, gyro drift,
  lux flicker detection.

### New audio (`audio/`)
- **AudioEngine** — AudioTrack PCM tones: QIDA pulse, SDE distortion, Omega hum,
  magnetic tick, interference alarm, composite mixer.

### New UI
- `ui/modes/ScanMode.kt` — 9 scan modes (JONES, MAGNETIC, QIDA, OMEGA, SDE,
  RESIDUAL, INTERFERENCE, SURVEY, ENTITY).
- `ui/modes/ModeUIs.kt` — all 8 mode screens from the spec (Jones classifier,
  magnetic field, QIDA, Omega trust, SDE, residual, interference, survey).
- `ui/entity/EntityModeUI.kt` — entity scan readout.
- `ui/entity/UltraOverlays.kt` — UltraColors palette, ultra grid, corner
  markers, animated entity ring (composite halo, confidence ring, pulse ring,
  interference flash).
- `ui/shader/LiveShader.kt` — animated shader layer over the camera feed.
- `ui/hud/NSCBHud.kt` — tactical HUD + MicroBar.
- `ui/diagnostics/NSCBDiagnostics.kt` — FPS/timing/jitter overlay.
- `ui/performance/NSCBPerformanceOverlay.kt` — perf overlay.

### Core changes
- `EntityOutput` extended with `residualLevel`, `residualConfidence`,
  `residualDelta` (fed from QIDA residual, survey score-EMA and z-mag).
- `ScanViewModel` now runs the full pipeline per sensor tick:
  entity engine → fusion → HUD → diagnostics → performance → audio, and
  exposes `currentMode` with `setMode()`.
- `LiveHud` rewritten as the v8.3 root screen: mode selector row, camera
  stack (preview + shader + grid + corners + entity ring), tactical HUD,
  mode router, calibration status, diagnostics/performance overlays.
- `MainActivity` now hosts the integrated `LiveHud(vm)`.

## Notes
- Package remains `com.nscb.spiritscan`; existing ONNX asset models and the
  math kernels (`ml/Kernels.kt`) are untouched.
- The spec's raw-resource ONNX loader (`OnnxModel`/`OnnxInferenceEngine`) was
  superseded by the repo's existing in-code kernel ports, which are already
  wired into `EntityEngine`.
- Target device: Samsung Galaxy S23 Ultra (minSdk 26, targetSdk 35).
